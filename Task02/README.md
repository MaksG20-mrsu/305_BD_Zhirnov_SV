# Task02

## Требования к окружению

Для работы необходимы:

- Python 3
- SQLite3
- Git Bash или Linux/macOS shell

## Запуск

Перейти в каталог `Task02` и выполнить:

    ./db_init.bat

Скрипт:

1. генерирует файл `db_init.sql` с командами создания и заполнения таблиц;
2. создаёт базу данных `movies_rating.db`;
3. создаёт и заполняет таблицы: movies, ratings, tags, users;

При повторном запуске таблицы удаляются и создаются заново.

## Результат

После выполнения `db_init.bat` должна быть создана заполненная база данных:

`movies_rating.db`
