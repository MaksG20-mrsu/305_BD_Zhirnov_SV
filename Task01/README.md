# Task01

В папке находятся файлы датасета MovieLens:

- `genres.txt` — жанры фильмов;
- `movies.csv` — информация о фильмах;
- `occupation.txt` — профессии пользователей;
- `ratings.csv` — оценки фильмов пользователями;
- `tags.csv` — пользовательские теги;
- `users.txt` — информация о пользователях;
- `ratings_count.txt` — количество оценок для пользователей с минимальным и максимальным количеством оценок;
- `sqlite.txt` — версия SQLite и полезные команды SQLite.
